Image formats

PNG vs. JPG: which should you use?

Use JPG for photographs and PNG for graphics that need crisp edges or transparency.

Choose JPG for photos

JPG files are usually much smaller than PNG files when the image is a photograph. That makes them a good choice for photos on websites, social posts, and email attachments. JPG uses compression, so some detail is discarded each time the file is saved.

Choose PNG for graphics

PNG keeps hard edges and text sharp. It also supports transparent backgrounds, which is useful for logos, icons, screenshots, and graphics placed over another color or image.

A quick rule

If it is mostly a photo, try JPG. If it has text, a logo, a screenshot, or transparency, choose PNG. You can convert an image with QuickSwitch whenever you need a different format.
