Text files

What is a CSV file?

A CSV is a simple text file used to move table-like data between apps.

CSV means comma-separated values

Each line is a row, and commas separate the values in each column. For example, a small contact list might have columns for name, email, and city.

Where you’ll see them

Spreadsheets, email tools, online stores, and analytics services commonly use CSV files for importing or exporting data. Most spreadsheet apps can open them.

Why format matters

Although CSV is plain text, it works best when the columns are consistent and values containing commas are wrapped in quotation marks. You can use QuickSwitch to make a simple text-format copy when needed.
